<h4>📄 DocuFlow AWS — Serverless Document Management</h4>

<p><b>🚧 Work in Progress</b></p>

<p>
  A serverless document management project exploring
  secure file uploads, document tracking and event-driven
  workflows using AWS managed services.
</p>

<ul>
  <li><b>Frontend:</b> React + TypeScript + Tailwind CSS</li>
  <li><b>Backend:</b> Node.js + AWS Lambda</li>
  <li><b>Infrastructure as Code:</b> AWS CDK + CloudFormation</li>
  <li><b>Storage:</b> Amazon S3</li>
  <li><b>Security:</b> IAM least-privilege permissions and HTTPS-only S3 access</li>
  <li><b>Uploads:</b> Lambda-generated presigned S3 URLs</li>
  <li><b>Testing:</b> Vitest</li>
</ul>

<p>
  The frontend includes document upload validation,
  upload progress, a document dashboard, search,
  filtering and document details.
</p>

<p>
  AWS infrastructure work includes provisioning secure
  S3 storage with CDK and implementing Lambda-based
  presigned upload functionality.
</p>

<p>
  Planned extensions include API Gateway, DynamoDB,
  Step Functions and additional workflow automation.
</p>

<p>
  The project is helping me deepen my understanding
  of serverless architecture, infrastructure as code,
  AWS security and event-driven application design.
</p>
